## Data written by this extension

- `node`: host label, measured directory, transport, mise version, failure state, drift, and optional error text. Label and directory are identifying; error text may contain secrets.

- `config`: host label, configuration path, trust state, and declared/effective tools. Paths and tool inventories are infrastructure-sensitive.
- `summary`: fleet counts, drift totals, and sweep timestamp. No direct personal fields, but fleet size and security posture are operationally sensitive.
