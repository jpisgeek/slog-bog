## Data written by this extension

- `node`: Host label, measurement and degradation state, failure classifications, transport, optional error detail, mise version, measured directory, counts, and drift. Labels and directories may identify machines, accounts, and projects; `errorDetail` may contain secrets when enabled.
- `tool`: Host label, tool and version data, installation and source paths, state, and drift. Paths can disclose home directories, private repositories, and internal domains.
- `config`: Host label, configuration path, trust state, and declared/effective tools. Paths can disclose account and project structure.
- `summary`: Aggregate fleet counts and sweep timestamp; no direct personal or secret fields.
