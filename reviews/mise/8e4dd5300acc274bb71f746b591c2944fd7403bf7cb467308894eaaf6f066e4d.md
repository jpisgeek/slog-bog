## Data written by this extension
- `node`: host label, measured directory, transport, mise version, failure state, counts, and optionally credential-bearing `errorDetail`.
- `tool`: host label, tool names and versions, install paths, source type/path, state, and drift. Paths may identify users, private repositories, domains, and projects.
- `config`: host label, full config path, trust state, and declared/effective tool inventories.
- `summary`: fleet size, drift totals, degradation counts, and sweep timestamp.
- Resource names and tags additionally expose readable forms of node labels, tool names, config paths, transport, and drift state.
