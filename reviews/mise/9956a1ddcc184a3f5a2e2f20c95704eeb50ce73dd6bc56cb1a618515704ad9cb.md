## Data written by this extension
- `node`: host label, transport, measured/degraded state, failure codes, optional host error text, mise version, measured directory, counts and drift. Host labels and directories are infrastructure-sensitive; `errorDetail` may contain secrets.
- `tool`: host and tool names, requested/resolved/latest versions, install path, source type/path, state and drift. Paths and sources may disclose accounts, projects, private repositories, internal domains or ordinary-looking secrets.
- `config`: host label, config path, trust state and declared/effective tool lists. Paths may expose account and project structure.
- `summary`: aggregate node/tool/drift counts and sweep time; no direct personal fields, though it describes fleet size and health.
- Resource names and tags additionally expose readable host labels, tool names, config-path slugs, transport and health/drift states.
