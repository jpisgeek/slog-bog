## Data written by this extension
- `node`: host label, measurement and degradation state, failed probes, error codes, optional sensitive `errorDetail`, mise version, measured directory, counts, drift, and transport.
- `tool`: host and tool names, requested/resolved/latest versions, install path, source type/path, status, and drift. Paths may expose usernames, private projects, repositories, or internal domains.
- `config`: host label, config path, trust state, declared/effective tools, and degradation state. Paths and tool inventories are infrastructure-sensitive.
- `summary`: fleet counts and sweep timestamp; no raw host paths or credentials.
- Resource names and tags additionally expose readable host labels, tool names, config-path slugs, transport, and state.
