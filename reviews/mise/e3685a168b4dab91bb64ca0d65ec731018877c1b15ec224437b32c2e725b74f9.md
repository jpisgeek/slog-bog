## Data written by this extension
- `node`: host label, measurement and degradation state, failed probes, failure classification, transport, optional error detail, mise version, evaluated directory, counts, and drift. Host labels, directories, and optional error detail are sensitive.
- `tool`: host and tool names, requested/resolved/latest versions, install and source paths, installation/activity state, and drift. Paths may reveal accounts, projects, private repositories, or internal domains.
- `config`: host, config path, trust state, declared/effective tools, and degradation state. Config paths and host/tool names are infrastructure-sensitive.
- `summary`: aggregate fleet counts and sweep timestamp; operationally sensitive but contains no direct credential field.
- Resource names and tags additionally expose host labels, tool names, config paths, transport, and measurement/drift state.
