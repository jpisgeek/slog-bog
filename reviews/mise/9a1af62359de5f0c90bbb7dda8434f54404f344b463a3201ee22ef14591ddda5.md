## Data written by this extension
- `node`: host label, measurement/degradation state, failed probes, transport, directory, mise version, error fields, counts, and drift. Host labels, directories, and optional `errorDetail` are sensitive.
- `tool`: host label, tool and version inventory, install path, source type/path, state, and drift. Paths and sources can expose accounts, private projects, repositories, or domains.
- `config`: host label, config path, trust state, and declared/effective tools. Paths and host labels are infrastructure-sensitive.
- `summary`: fleet counts and sweep timestamp. This exposes operational fleet size and posture but no direct credential.
- Resource names and tags additionally expose readable host labels, tool names, config-path slugs, drift, transport, and degradation state.
