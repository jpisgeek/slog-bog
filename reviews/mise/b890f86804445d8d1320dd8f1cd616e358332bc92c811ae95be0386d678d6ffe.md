## Data written by this extension

- `node`: host label, measurement/failure state, transport, mise version, measured directory, counts, drift, and optional error text. Labels, directories, and error details may be identifying or sensitive.
- `tool`: host label, tool and version inventory, installation and activity state, install path, source type/path, latest version, and drift. Paths and sources may expose usernames, private repositories, internal domains, or secrets missed by screening.
- `config`: host label, configuration path, trust state, and declared/effective tool inventory. Paths and inventories are infrastructure-sensitive.
- `summary`: aggregate fleet counts and sweep timestamp; no direct personal field, though totals describe fleet size and condition.
- Resource names and tags additionally expose host labels, tool names, configuration-path slugs, transport, and health/drift states.
