## Data written by this extension
- `node`: host label, measurement/degradation state, failure codes, transport, optional error detail, mise version, measured directory, counts, and drift. Host labels and directories identify infrastructure; optional error detail may contain sensitive host output.
- `tool`: host label, tool and version information, install path, source type/path, installation/activity/outdated state, and drift. Paths and sources may reveal accounts, projects, private repositories, or internal domains.
- `config`: host label, config path, trust state, declared/effective tools, and stale/degraded state. Host labels and config paths are infrastructure-sensitive.
- `summary`: aggregate fleet counts and sweep timestamp; no direct credential or personal field.
