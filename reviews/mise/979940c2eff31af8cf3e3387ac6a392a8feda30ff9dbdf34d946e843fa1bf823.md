## Data written by this extension
- `node`: host label, transport, measured/degraded state, failure codes, optional secret-bearing `errorDetail`, mise version, measured directory, counts, and drift.
- `tool`: host and tool names, requested/resolved/latest versions, install and source paths, installation/activity state, and drift. Paths may identify accounts, projects, internal domains, or private repositories.
- `config`: host label, config-file path, trust state, and declared/effective tool inventories.
- `summary`: aggregate fleet counts and sweep timestamp; no direct personal fields.
- Resource names and tags expose readable host labels, tool names, config-path fragments, transport, and health/drift state.
