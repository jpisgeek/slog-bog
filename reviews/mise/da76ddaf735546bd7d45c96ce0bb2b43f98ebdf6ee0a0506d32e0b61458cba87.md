## Data written by this extension
- `node`: host label, measurement/degradation state, failed probes, failure codes, optional error detail, transport, mise version, measured directory, counts, and drift. Host labels and paths identify infrastructure; `errorDetail` may contain secrets when enabled.
- `tool`: host and tool names, requested/resolved/latest versions, install and source paths, source type, installed/active/outdated state, and drift. Paths may expose usernames, private repositories, or internal domains.
- `config`: host label, config path, trust state, and declared/effective/missing tools. Paths and labels identify hosts, accounts, and projects.
- `summary`: fleet size, measurement/degradation totals, drift totals, and sweep timestamp.
- Resource names and tags additionally expose normalized host labels, tool names, config paths, transport, and health/drift states.
