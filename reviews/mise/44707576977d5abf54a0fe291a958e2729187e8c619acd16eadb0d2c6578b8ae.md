## Data written by this extension
- `node`: host label, measurement and degradation state, failed probes, error codes, optional sensitive `errorDetail`, mise version, measured directory, counts, transport, and drift. Host labels appear in resource names and tags.
- `tool`: host label, tool and version inventory, install path, source type/path, state, and drift. Paths and sources may identify accounts, projects, private repositories, or internal domains; host and tool labels appear in names and tags.

- `summary`: aggregate fleet counts and sweep timestamp; no direct personal or credential field is expected.
