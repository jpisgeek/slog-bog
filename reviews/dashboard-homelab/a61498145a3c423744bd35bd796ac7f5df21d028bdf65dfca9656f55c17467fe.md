## Checked and clean
1. Secrets/identifying info: swept all four files (code, comments, string literals, README prose, manifest) for credentials, keys, PEM blocks, tokens, hostnames, non-vendor domains, IPs/ranges, emails, MACs, serials, secret-store paths, local filesystem paths, and raw control bytes — none present; the only literal control character is the visible `"\u001f"` escape (greppable, covered in finding 6), and the only real-person/real-identity strings are the intentional public `@jpisgeek`/GitHub identity and the LICENSE name (finding 9).
2. Credential handling: the report accepts no arguments and performs no vault, environment, or process access, so no secret can enter logs, details, or persisted output; the one error-path leak of non-secret payload fragments is finding 1.
3. Transport/network: the code makes no network calls of any kind (no fetch, no sockets, no cleartext opt-out, no TLS options to disable, nothing to time out); the only URL-shaped surface is the contract schema laxity in finding 5.
4. Untrusted input: every record is schema-validated before use, unknown resource types and unreadable content are rejected into `partial` completeness, no HTML/shell/SQL/path construction from input exists, and the markdown renderer interpolates only validated numbers and constant strings — remaining gaps are findings 2, 3, 4, 6, and 7.
5. Supply chain: the single import is `npm:zod@4`, which is the sanctioned platform-supplied specifier; there are no other dependencies, no dynamic `import()`, no remote fetch-and-execute, and no `eval`/`new Function`/code deserialisation.
6. Documentation vs code: verified extension name, version (`2026.08.25.1` in README, manifest, and producer), install command, report/data names (`report-jpisgeek-dashboard-homelab-json`), example config, scope (`method`), and the TrueNAS alert/certificate-independence caveat all match the code — the drifts found are the security claim in finding 1, the healthy-values claim in finding 2, and the filtered-coverage claim in finding 4.
7. Data written: enumerated below; the README's Security section correctly discloses the operational classification and tells the user to protect rendered dashboards.

## Data written by this extension
- One report artifact per collector execution: rendered markdown plus a JSON dashboard bundle (`report-jpisgeek-dashboard-homelab-json`), classified `operational`.
- The bundle can contain: Netdata node names, alarm names and free-text alarm info, mount paths and usage percentages; TrueNAS pool names and status, certificate names and expiry dates, alert free text (`formatted`, which may embed hostnames, serials, or IPs from TrueNAS itself); Firewalla machine names, network names, and device counts; collector model name and model ID in `producer` and exception subjects.
- Rejection exception details include data-handle names, and on the malformed-JSON path may include payload fragments (finding 1).
- Parsed but **not** written: Firewalla per-device MAC/IP/traffic inventory, TrueNAS disk serials and system records, netdata node hostnames/OS details, and the Firewalla `mspDomain` — validated for completeness accounting only.
- No secrets are handled anywhere in the pipeline, so no write can include one.
