## Data written by this extension
- No datastore resources are created; the extension returns Markdown and a JSON dashboard bundle.
- Producer metadata: extension/version, collector type, private model name and model ID, data name, report name, and generation time.
- Netdata: reachability counts, node names and errors, alarm names/details/values, mount paths, and utilization.
- TrueNAS: pool names, status and utilization; certificate names and expiry details; alert classes, formatted messages, severity, and dismissal state.
- Firewalla: online/total counts, machine names, network names, and offline-machine details. Device IPs, MAC addresses, GIDs, MSP domain, and disk serials are validated but not emitted.
- Rejection exceptions: data-handle names and potentially arbitrary repository error messages.
- Personal/sensitive operational fields include model identifiers, host or machine names, network and mount names, certificate names, and free-form diagnostics that could contain secrets.
