## Data written by this extension
- `vmHost`: host name, processor and memory capacity, VM storage filesystem path, VM count, and switch count. Host name and path are infrastructure-sensitive.
- `vm`: VM name, state, status, generation, processor count, assigned memory, and uptime. VM name and state expose inventory.
- `checkpoint`: VM name, checkpoint name and type, creation time, and parent checkpoint name. These expose operational history.
- `vmSwitch`: virtual-switch name and type. The name exposes network inventory.
- All resource IDs include a readable slug derived from configured `user@host:port`; tags additionally expose VM names, states, and VM counts. No credential or key material is written.
