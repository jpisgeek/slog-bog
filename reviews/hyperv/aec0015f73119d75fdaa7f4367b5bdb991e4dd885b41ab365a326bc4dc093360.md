## Data written by this extension
- `vmHost`: machine name, processor and memory capacity, VM storage path, VM count, and switch count. The name and path are infrastructure-sensitive; the path may contain personal/account identifiers.
- `vm`: VM name, state, status, generation, CPU count, assigned memory, and uptime. The ID contains readable host and VM names; state is also tagged.
- `checkpoint`: VM and checkpoint names, checkpoint type, creation time, and parent name. The ID contains readable host, VM, and checkpoint names; the VM name is tagged.
- `vmSwitch`: switch name and type. The ID contains readable host and switch names.
- All resource kinds have infinite lifetime. No credential is intentionally written, but names, paths, and remotely supplied descriptive fields can contain sensitive infrastructure data.
