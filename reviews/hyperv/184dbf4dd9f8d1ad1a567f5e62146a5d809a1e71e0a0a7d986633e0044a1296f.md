## Data written by this extension
- `vmHost`: host name, processor and memory capacity, VM storage filesystem path, VM count and switch count. The name and path are sensitive infrastructure identifiers.
- `vm`: VM name, state, status, generation, CPU count, assigned memory and uptime. This is a device inventory.
- `checkpoint`: VM name, checkpoint name and parent, checkpoint type and creation timestamp. Names identify infrastructure and operational history.
- `vmSwitch`: virtual-switch name and type. The name identifies network infrastructure.
- Resource IDs: readable host, VM, checkpoint and switch-name slugs plus hashes.
- Tags: VM count, VM state, and raw VM name.
