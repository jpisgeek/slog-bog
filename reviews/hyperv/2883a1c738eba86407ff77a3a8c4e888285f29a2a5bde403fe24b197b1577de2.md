## Data written by this extension
- `vmHost` (infinite): host name, processor and memory capacity, VM filesystem path, VM count and switch count. These are sensitive infrastructure inventory fields.
- `vm` (infinite): VM name, state, status, generation, CPU count, assigned memory and uptime; state is also tagged. Names identify infrastructure.
- `checkpoint` (infinite): VM and checkpoint names, checkpoint type, creation time and parent name; VM name is also tagged.
- `vmSwitch` (infinite): virtual-switch name and type.
- Resource IDs expose lowercase host, VM, checkpoint and switch names alongside a digest; no password, key or login user is intentionally stored.
