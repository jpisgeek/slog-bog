## Data written by this extension
- All resource IDs: readable configured `host:port` plus host, VM, switch, or checkpoint names and a SHA-256 digest.
- `vmHost`: hostname, processor and memory capacity, VM storage filesystem path, VM count, and switch count.
- `vm`: VM name, state, status, generation, CPU count, assigned memory, uptime, and a state tag.
- `checkpoint`: VM and checkpoint names, checkpoint type, creation timestamp, parent name, and a VM-name tag.
- `vmSwitch`: switch name and type.
- No password, private key, console credential, or guest filesystem contents are written.
