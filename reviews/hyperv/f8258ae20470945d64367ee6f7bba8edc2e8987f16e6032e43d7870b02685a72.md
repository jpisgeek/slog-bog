## Data written by this extension
- `vmHost`: hostname, processor and memory capacity, local VM filesystem path, VM count, and switch count. Hostname, capacity, path, and ID are sensitive infrastructure inventory.
- `vm`: VM name, state, status, generation, CPU, memory, and uptime. Names, IDs, operational state, and uptime are sensitive infrastructure/activity data.
- `checkpoint`: VM and checkpoint names, type, creation time, and parent name. Names, IDs, topology, and timestamps are sensitive infrastructure/activity data.
- `vmSwitch`: switch name and type. The name and embedded resource ID are sensitive network-infrastructure data.
- All four resource kinds have infinite lifetime; no intended resource field contains authentication credentials.
