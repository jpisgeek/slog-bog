## Data written by this extension
- `vmHost`: reported machine name, processor/memory capacity, full VM storage path, VM/switch counts; ID also exposes slugged login, host, port, and reported name.
- `vm`: VM name, state, status, generation, CPU, assigned memory, and uptime; ID exposes target and VM name; state is a queryable tag.
- `checkpoint`: VM/checkpoint names, type, creation timestamp, and parent name; ID exposes target and both names; VM name is a queryable tag.
- `vmSwitch`: switch name and type; ID exposes target and switch name.
- These records contain identifying infrastructure inventory. `virtualMachinePath` can reveal host volume, server, share, or user-directory naming. Raw remote text fields could contain sensitive text as described in finding 9.
