## Data written by this extension
- `vmHost`: host name, processor and memory capacity, VM storage filesystem path, VM count and switch count. The ID exposes the host name.
- `vm`: VM name, state, status, generation, CPU count, assigned memory and uptime. The ID exposes host and VM names; the `state` tag exposes state.
- `checkpoint`: VM name, checkpoint name, type, creation timestamp and parent name. The ID exposes host, VM and checkpoint names; the `vm` tag exposes the VM name.
- `vmSwitch`: switch name and type. The ID exposes host and switch names.
