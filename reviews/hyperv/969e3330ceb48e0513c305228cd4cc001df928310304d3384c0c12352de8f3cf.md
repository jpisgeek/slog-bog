## Data written by this extension
- `vmHost`: host name, processor/memory capacity, VM storage path, VM/switch counts; IDs expose configured target and reported host identity.
- `vm`: VM name, state, status, generation, CPU/memory and uptime; IDs expose host and VM names, and state is tagged.
- `checkpoint`: VM/checkpoint/parent names, type and creation time; IDs and tags expose VM/checkpoint identities.
- `vmSwitch`: switch name and type; IDs expose host and switch identities.
- Intended fields contain no credentials, but unscreened remote strings can currently introduce sensitive content as described above.
