## Data written by this extension
- `vmHost`: reported host name, processor and memory capacity, VM filesystem path, VM and switch counts; ID also exposes configured `user@host:port`, and `vmCount` is tagged.
- `vm`: VM name, state, status, generation, processor count, assigned memory, and uptime; ID exposes target and VM name, and state is tagged.
- `checkpoint`: VM and checkpoint names, checkpoint type, creation time, and parent name; ID exposes target and both names, and VM name is tagged.
- `vmSwitch`: switch name and type; ID exposes target and switch name.
- No credential field is intentionally written. Host/user identifiers, machine names, inventory, and `virtualMachinePath` are sensitive infrastructure data; remotely supplied status and path text could also contain unexpected sensitive content.
