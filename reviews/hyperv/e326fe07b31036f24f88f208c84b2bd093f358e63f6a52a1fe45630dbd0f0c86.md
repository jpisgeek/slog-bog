## Data written by this extension

- `vmHost`: machine name, processor and memory capacity, VM storage filesystem path, VM count, and switch count.
- `vm`: VM name, state, status, generation, CPU and memory allocation, and uptime.
- `checkpoint`: VM, checkpoint and parent names, checkpoint type, and creation timestamp.
- `vmSwitch`: switch name and type.
- Resource IDs and tags additionally expose the configured SSH user/host/port, VM/checkpoint/switch names, VM state, and counts.
