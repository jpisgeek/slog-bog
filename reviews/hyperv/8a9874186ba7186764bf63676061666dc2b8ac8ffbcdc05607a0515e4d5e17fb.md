## Data written by this extension
- `vmHost`: reported hostname, processor and memory capacity, VM storage path, VM count, and switch count. The name and path identify infrastructure.
- `vm`: VM name, state, status, generation, CPU count, assigned memory, and uptime. VM name and operational state are inventory data.
- `checkpoint`: VM name, checkpoint name and type, creation time, and parent checkpoint name. These are infrastructure and operational-history data.
- `vmSwitch`: switch name and type. The name identifies network infrastructure.
- Every resource ID includes readable, slugged configured login-user and host information; VM state, VM name, and VM count also appear in tags. No passwords, private keys, or console credentials are written.
