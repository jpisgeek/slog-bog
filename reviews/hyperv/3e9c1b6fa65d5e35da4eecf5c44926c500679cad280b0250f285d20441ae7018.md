## Data written by this extension
- `vmHost`: reported host name, processor and memory capacity, VM storage path, VM/switch counts; ID also exposes slugged login user, host, port and reported host name.
- `vm`: VM name, state, status, generation, CPU, assigned memory and uptime; ID exposes target and VM name, with state indexed as a tag.
- `checkpoint`: VM/checkpoint names, type, timestamp and parent name; ID exposes target and both names, with VM name indexed as a tag.
- `vmSwitch`: switch name and type; ID exposes target and switch name.
- Names, paths, status text and checkpoint metadata are infrastructure-sensitive and could contain operator-chosen sensitive text; no credential field is intentionally collected.
