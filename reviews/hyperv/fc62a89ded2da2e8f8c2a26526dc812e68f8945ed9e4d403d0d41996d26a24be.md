## Data written by this extension
- `vmHost`: host name, processor and memory capacity, VM storage path, VM count and switch count. The name, path and target-derived ID are infrastructure-sensitive.
- `vm`: VM name, state, status, generation, CPU count, assigned memory and uptime. The name, target-derived ID and state tag expose inventory.
- `checkpoint`: VM name, checkpoint name and type, creation time and parent name. Its ID and `vm` tag expose inventory.
- `vmSwitch`: switch name and type. Its name and target-derived ID expose network inventory.
- No passwords, private keys, tokens, MAC addresses or guest contents are written.
