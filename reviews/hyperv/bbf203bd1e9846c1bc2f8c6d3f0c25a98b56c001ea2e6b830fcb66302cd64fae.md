## Data written by this extension
- `vmHost`: host name, processor and memory capacity, VM storage filesystem path, VM count, switch count, and a `vmCount` tag.
- `vm`: VM name, state, status, generation, CPU count, assigned memory, uptime, and a `state` tag.
- `checkpoint`: VM and checkpoint names, checkpoint type, creation time, parent checkpoint name, and a VM-name tag.
- `vmSwitch`: switch name and switch type.
- All resources have infinite lifetime. IDs additionally expose the configured SSH user, host and port plus readable inventory names. Names, status text, paths, and tags are sensitive infrastructure data and could contain personal or secret material if operators embed it in those values.
