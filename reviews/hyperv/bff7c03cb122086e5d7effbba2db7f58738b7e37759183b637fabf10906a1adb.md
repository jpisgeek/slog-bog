## Checked and clean
1. Secrets and identifying information on the published surface: no credentials, real private endpoints, local operator paths, secret-store names, hidden control bytes, or non-placeholder infrastructure identifiers found; accepted publisher, license, package, and repository identities were excluded.
2. Credential handling: see findings 4–6; host and user are marked sensitive, no password or key material is accepted, and remote stderr and malformed output are not copied into errors.
3. Transport and network: SSH encryption, strict host-key checking, public-key-only authentication, forwarding restrictions, output limits, total/connect timeouts, and caller cancellation are present; there is no cleartext option or URL-fetch surface.
4. Untrusted input: see findings 1–3 and 7; PowerShell names are quoted, wildcards and dangerous name characters are rejected, required response collections are not defaulted to empty, and failure is not converted into healthy zero counts.
5. Supply chain: clean; the only external import is the sanctioned `npm:zod@4`, with no dynamic imports, undeclared dependencies, fetched code, `eval`, or `new Function`.
6. Documentation matches code: see findings 1–2 for the inaccurate collision guarantee; method names, arguments, resource fields, destructive behavior, examples, and remaining failure behavior otherwise match.
7. Data written: see finding 4; the README enumerates the inventory fields and readable identifiers, and no designed credential or key field is written. Finding 3 permits arbitrary untrusted string content until corrected.

## Data written by this extension
- `vmHost`: reported host name, processor and memory capacity, VM storage filesystem path, VM count, and switch count. Its ID also exposes the configured host and port.
- `vm`: VM name, state, status, generation, CPU count, assigned memory, and uptime; the state is also a tag.
- `checkpoint`: VM and checkpoint names, checkpoint type, creation timestamp, and parent checkpoint name; the VM name is also a tag.
- `vmSwitch`: virtual-switch name and type.
- No intended password, private key, token, or console credential fields; unconstrained remote strings in finding 3 could nevertheless carry arbitrary sensitive content.
