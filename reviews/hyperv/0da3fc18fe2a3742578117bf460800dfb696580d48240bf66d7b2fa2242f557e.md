## Data written by this extension
- `vmHost`: reported host name, processor and memory capacity, VM storage path, VM/switch counts, and `vmCount` tag. Host name, login user, configured address, port, and storage path are infrastructure-sensitive.
- `vm`: VM name, state, status, generation, CPU count, assigned memory, uptime, and state tag. VM and connection identities are infrastructure-sensitive.
- `checkpoint`: VM/checkpoint/parent names, checkpoint type, creation timestamp, and VM tag. These expose infrastructure and operational history.
- `vmSwitch`: switch name and type. Switch and connection identities are infrastructure-sensitive.
- No passwords, private keys, session credentials, or guest contents are written.
