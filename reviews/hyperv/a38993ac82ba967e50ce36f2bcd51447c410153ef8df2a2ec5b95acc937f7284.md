## Checked and clean
1. Published surface: no credentials, private keys, real infrastructure values, local paths, control characters, or non-placeholder secret-store names found; accepted publisher, package, repository, vendor, and LICENSE identities were excluded.
2. Credential handling: `host` and `user` are marked sensitive; no password or private-key argument, disk persistence, or URL credential transport exists; see findings 1–4 for identifier and SSH-selection exposure.
3. Transport and network: SSH encryption, strict host-key checking, public-key-only authentication, forwarding suppression, bounded output, timeouts, and caller cancellation are present; see finding 4.
4. Untrusted input: names reject wildcards, controls, padding, and display-formatting characters; PowerShell values are quoted, responses are schema-parsed, identifiers are collision-framed, and failures are not converted to healthy counts; see finding 1.
5. Supply chain: only sanctioned `npm:zod@4` is imported; no unapproved dependency, dynamic remote import, fetched execution, `eval`, or `new Function` found.
6. Documentation matches code for methods, arguments, resources, destructive guards, identifier format, and data fields; see finding 1 for the false claim that all remote output is screened from messages.
7. Data writes: README discloses the resource fields and inventory exposure; see findings 2–3.

## Data written by this extension
- `vmHost` (infinite): host name, processor and memory capacity, VM filesystem path, VM count, and switch count. Host name, target-derived ID, and filesystem path are sensitive infrastructure inventory.
- `vm` (infinite): VM name, state, status, generation, CPU count, assigned memory, and uptime. VM names, readable IDs, and state tags identify infrastructure.
- `checkpoint` (infinite): VM name, checkpoint name and type, creation time, and parent name. Names, IDs, and VM tags identify infrastructure and operational history.
- `vmSwitch` (infinite): switch name and type. Switch names and readable IDs identify network infrastructure.
- No credential field is intentionally written.
