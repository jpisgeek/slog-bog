## Checked and clean
1. Secrets and identifying information: Every one of the 29 embedded files was scanned, as were code, comments, test data and prose. That covers the 19 manifest payload files plus the 10 GitHub-source files: the root README, 6 TypeScript test files, `probe_test.py`, `readme.vars.yaml` and `test_fixtures.ts`. The scans looked for:
   - IPv4 and IPv6 literals and MAC addresses;
   - email addresses and non-example domains;
   - user and volume filesystem paths and file URLs;
   - credential and private-key patterns, and `vault.get` item names;
   - control or NUL bytes.

   Nothing was found. The matches were the policy-permitted generic OS interfaces (`/System/Volumes/Data`, `/System/Library/CoreServices/SystemVersion.plist`, `/etc/os-release`), vendor product names in the root package index, and generic product labels such as "Mac Mini" and "Mac Studio". The new `fixtureRecord` uses all-zero UUIDs and `example` names.
2. Credential handling: Neither behavior accepts or stores a credential, so no field needs `sensitive`. The new logging was checked in full:
   - It emits behavior names, target counts, cycle IDs, totals, the two-value `failureKind` enum, and per-gap id, state and fixed reason strings.
   - It never logs raw exceptions, paths, command output or stderr.
   - Transport `stderr` is only pattern-tested and never persisted.

   The new thrown errors name behaviors, cycle UUIDs and workflow run IDs only. A malformed run identity is never echoed: `evidenceRun` now throws a message naming only the source behavior, and the tests assert that a sentinel value is absent from errors, the stored observations and logs. `createFleetHandler` still rejects report URLs with userinfo, query or fragment, and holds no credential.
3. Transport and network: The behaviors make no network calls. The host adapter requires an `https:` report URL and has no cleartext or TLS-disable option. It enforces exact-origin and same-origin refresh with the `X-Fleet-Action` header and a bodyless POST, with an overall timeout from 10 ms to 120 s. Callbacks receive an abort signal, and interruption becomes a generic 503 without an unhandled rejection. The browser fetch uses `redirect: "error"`. `fleet_host.ts` and `fleet_controls.ts` are byte-identical to the previously reviewed content and were re-read.
4. Untrusted input: Owned contracts and global arguments are now `strictObject`: `Cycle`, `LocalProbe`, `Collected`, `Policy`, `State`, `totals`, `operatingSystems`, both behaviors' `Globals`, and method arguments. Before strict parsing, SSH evidence is narrowed to exactly six named fields by `transportFields`. There is no `.passthrough()`, `any` or `as` cast on parsed data; the remaining casts are typed record narrowing ahead of strict parses. Rendering is in `fleet_view.ts`, which is unchanged, escapes text and attribute contexts, and embeds JSON with `<` escaped. No shell, SQL or file-path construction uses input. Instance names are fixed literals. Failures map to explicit gaps such as `unavailable`, `access-required`, `unsupported` and `stale`, never to healthy. A malformed transport run identity now becomes a per-system `unavailable` gap instead of aborting the scan; other targets are still observed (tested). `ownEvidence` fails rather than mixing versions, and `newestEvidence` ranks by validated timestamps, not array order.
5. Supply chain: Production imports are `npm:zod@4` (sanctioned) and relative modules only. The tests import `jsr:@swamp-club/swamp-testing@0.20261105.71`, which is pinned exactly. There is no dynamic `import()`, `eval` or `new Function`. `probe_source.ts` is a fixed string, not executed by the extension.
