## Checked and clean
1. Secrets/identifying info: all four files read; no credentials, keys, PEM, cookies, IPs, hostnames, emails, serials, MACs, local paths, or vault item paths; all examples use `example`/`your-msp-domain`/`myvault`/`Example Firewalla`; byte-level grep for control chars (0x00–0x08, 0x0B–0x0C, 0x0E–0x1F, 0x7F) on the on-disk files returned 0 hits (non-ASCII bytes are only em-dashes and a middle dot). See findings 7 and 9 for the only operator-environment mentions.
2. Credential handling: `token` is `.meta({ sensitive: true })`; sent only in a header; never logged, never written to a resource/tag/instance name/URL; 401/403 body is discarded, other error bodies pass through `redact()` — see findings 1 and 2.
3. Transport: request URL is always `https://<validated hostname>/v2/devices`; `mspHost` parses via `URL`, rejects userinfo/port/path/query/fragment and enforces `*.firewalla.net` on `hostname` (verified the `evil.example/#.firewalla.net` and backslash cases are rejected); no TLS-disable option; timeout via `AbortSignal.timeout`; caller cancellation distinguished as `CANCELLED` — see findings 3 and 6.
4. Untrusted input: no HTML, shell, SSH, SQL, or file-path construction from API data; resource names slugged + FNV-hashed over `gid|mac|id` / machine name; fetch/HTTP/JSON failures throw rather than write — see findings 4 and 5.
5. Supply chain: sole import is `npm:zod@4` (sanctioned bare major); `dependencies: []`; no dynamic import, eval, `new Function`, or fetched code.
6. Docs vs code: argument names/types/defaults, method name and count, resource names and field lists, example config all match — see findings 1 and 8.
7. Data written: see section below; README Security section discloses that the datastore holds device names, MACs, IPs, vendors, networks, online state, traffic totals. No write can include the token.

## Data written by this extension
- `device` (one per Firewalla device, lifetime infinite): `name`, `ip`, `mac`, `macVendor`, `deviceType`, `network`, `online`, `ipReserved`, `isRouter`, `isFirewalla`, `totalDownload`, `totalUpload`, `tier`, `sshCandidate`, `excluded`, `gid`; tags `tier`, `network`, `deviceType`, `online`, `sshCandidate`, `machine`. **Personal data:** device names, MAC addresses, private IPs, traffic totals, network names.
- `machine` (one per collapsed host): `name`, `primaryIp`, `deviceType`, `macVendor`, `tier`, `sshCandidate`, `online`, `networks`, `interfaces[]` (`name`, `ip`, `mac`, `network`, `online`), `interfaceCount`, `dependsOn`; tags `tier`, `online`, `sshCandidate`, `multiHomed`, `dependsOn`. **Personal data:** host names, MACs, IPs, network membership, operator-declared dependency graph.
- `inventory` (single roll-up): `mspDomain` (operator's MSP tenant hostname), counts by tier/state, `excludedNetworks`, `networks` list, `deviceTypes` histogram, `syncedAt`. **Personal data:** MSP tenant name, VLAN/network names.
- No secret is written to any resource, tag, name, or log. Full unfiltered sync deletes stored `device-*`/`machine-*` records not in the current response (see finding 4).
