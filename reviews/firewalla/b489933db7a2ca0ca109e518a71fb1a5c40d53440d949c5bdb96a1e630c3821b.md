## Data written by this extension
- `device`: IDs and group IDs, device names, IP and MAC addresses, vendors, types, networks, status, reservation/router state, traffic totals, tier, exclusion state, and SSH candidacy. This is personal and infrastructure-identifying data.
- `machine`: machine names, primary IPs, types, vendors, tier, online state, networks, interface names/IPs/MACs, dependency topology, and SSH candidacy. This is personal and infrastructure-identifying data.
- `inventory`: MSP hostname, device and machine counts, excluded-network names and counts, network names, device-type histogram, and synchronization time. This identifies private network infrastructure.
- Resource names and tags additionally contain MAC-derived identifiers, machine names, networks, device types, dependency names, online state, and SSH-candidate state. No token is written.
