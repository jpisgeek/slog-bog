## Checked and clean
1. Secrets/identifying info: all four published files read in full — no tokens, keys, PEM, hostnames, IPs, vault item paths, local filesystem paths, or private model names; every example uses `example.com`/`myvault`/`ExampleService`; no visible control characters in string literals. Only the LICENSE name (finding 9).
2. Credential handling: `apiToken` is `.meta({ sensitive: true })` in both models; sent only as a Bearer header; userinfo in `baseUrl` rejected by schema; not logged, not written to resources or tags, not persisted; catch blocks redact body text — see findings 1, 2, 8 for the residual paths.
3. Transport: `https://`/`http://` only (file:/data: rejected); no TLS-disable option; `AbortSignal.timeout` on every fetch combined with the caller signal; cancellation distinguished from timeout by checking `ctx.signal.aborted` directly; Retry-After wait is capped and abortable. Hostname validation is N/A (generic OpenAI-compatible endpoint, user-supplied). See findings 3, 5.
4. Untrusted input: no HTML, shell, SQL, or path interpolation; instance names are `prefix-slug-sha256[0:4]` with fixed prefixes (collision-resistant, filesystem-safe); `models`/`health` use fixed names; failures carry `errorKind`, `dimensionKnown`, `checksCompleted`, `reachable/authorized` separately — not disguised as health. Response parsing is manual shape-checking with casts rather than zod schemas; see finding 4 for the one absent→finding case.
5. Supply chain: sole import `npm:zod@4` (sanctioned bare major); `dependencies: []`; no dynamic import, eval, `new Function`, or remote fetch-and-execute.
6. Docs match code: argument names/defaults, method names and counts (2 + 3), resource names and field lists, instance-name format, throw-vs-write behaviour, and the example config all match the source; see findings 1, 6, 7 for the drift found.
7. Data written: see section below; no MACs, users, or device inventories; caller prompts are not stored.

## Data written by this extension
- `models` (endpoint): `modelIds` (served model ids — may reveal private fine-tune names), `modelCount`, `syncedAt`; tag `modelCount`.
- `health` (endpoint): `reachable`, `authorized`, `httpStatus`, `latencyMs`, `errorKind`, `error` (runtime error text — may include the request URL, finding 1), `checkedAt`.
- `embeddingProbe`: `model`, `servesEmbeddings`, `measuredDimension`, `dimensionKnown`, `latencyMs`, `httpStatus`, `errorKind`, `error` (≤160 chars of endpoint body, token-redacted), `checkedAt`; tags include raw `model` id.
- `completionProbe`: `model`, latency/status, `finishReason`, token counts, `reasoningChars`, `contentChars`, `emptyContentWithReasoning`, `contextExhausted`, `maxTokensHit`, `errorKind`, `error`, `checkedAt`. Prompt and completion text are not stored.
- `capabilityProbe`: `model`, three boolean findings, `checksCompleted`, three `*Truncated` flags, `latencyMs`, `errorKind`, `error`, `checkedAt`.
- No secret is written by design; the only secret-adjacent fields are the `error` strings covered by findings 1 and 2.
