## Data written by this extension
- `models`: served model identifiers, count, and timestamp. Model identifiers may disclose deployment or naming information.
- `health`: reachability, authorization result, HTTP status, latency, error classification, error text, and timestamp.
- `embeddingProbe`: model identifier, embedding capability and dimension measurements, latency, status, error data, and timestamp.
- `completionProbe`: model identifier, latency, status, finish reason, token counts, reasoning/content lengths, diagnostic flags, error data, and timestamp.
- `capabilityProbe`: model identifier, capability results, completion/truncation counts, latency, error data, and timestamp.
- `daemon`: daemon status plus loaded model identifiers, types, and architectures. This is operational inventory and may be identifying.
- Error fields can contain screened fragments of echoed prompts or inputs and, because of finding 1, potentially a long bearer-token prefix.
