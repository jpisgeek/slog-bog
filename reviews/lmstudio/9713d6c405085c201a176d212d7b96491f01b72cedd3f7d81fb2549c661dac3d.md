## Data written by this extension
- `models`: served model IDs, model count, and synchronization time. Model IDs may reveal private model inventory; the README discloses this.
- `health`: reachability, authorization state, HTTP status, latency, error classification/text, and check time.
- `embeddingProbe`: model ID, embedding capability/dimension, latency, status, error classification/text, and check time. Error text can currently contain sensitive echoed response content.
- `completionProbe`: model ID, latency, status, finish reason, token counts, reasoning/content lengths, diagnostic flags, error classification/text, and check time. The prompt is not written directly, but an endpoint can echo it into the stored error field.
- `capabilityProbe`: model ID, capability booleans, completion/truncation counts, latency, error classification/text, and check time. Error text can currently contain sensitive echoed response content.
- `daemon`: CLI/daemon status, loaded-model count, loaded model identifiers, types and architectures, timestamps, and canned errors. This is environment inventory; the README discloses it.
