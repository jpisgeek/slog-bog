## Checked and clean
1. Secrets/identifying info: scanned all five published files (code, comments, strings, README prose, examples) — no credentials, keys, PEM blocks, IPs, private hostnames/domains, local filesystem paths, vault item names, or serials; only public `github.com/jpisgeek/slog-bog` links; example values (`/srv/swamp/example-repo`, `/usr/local/bin/swamp`) are generic; byte-level scan found no control characters or NULs; LICENSE name → finding 8.
2. Credential handling: `token` is `.meta({ sensitive: true })`, passed only via child env `SWAMP_SERVER_TOKEN` (line 153), never in argv/logs/resource errors/bundle output; all stored `error` strings come from fixed `safeError()` text; stderr/stdout on failure are regex-classified then discarded; nothing writes a secret to disk — except the URL-userinfo gap → findings 1–2.
3. Transport: every spawn has a timeout (`AbortSignal.timeout` + `AbortSignal.any`), caller abort is re-thrown not misreported, no TLS-verification disable exists (TLS is delegated to the Swamp CLI); vendor-domain pinning is N/A (operator's own serve endpoint) — scheme/userinfo gaps → findings 1–2, timeout labeling → finding 6.
4. Untrusted input: fixed argv array via `Deno.Command`, no shell, no string-built commands; resource/exception IDs derive from a closed enum, no collision; no HTML rendering (markdown interpolates only fixed strings and counts); empty history → `unknown` not healthy, unrecognized statuses → `degraded`, missing interface snapshots → `partial` with exception; the `.passthrough()` schemas validate the self-produced bundle (versioning choice), not untrusted responses, and CLI payload is consumed via typeof-checked helpers — except the doctor `stale` backfill → finding 3.
5. Supply chain: the only import in both modules is `npm:zod@4` (the sanctioned runtime-supplied bare major); no other npm/jsr/https imports, `dependencies: []`, no dynamic `import()`, no `eval`/`new Function`, no code deserialization — clean.
6. Docs vs code: extension name, version (README = manifest = model = producer), install command, argument table (names, types, defaults, required), single `observe` method and its description, resource name/lifetime/fields, failure caveats, and the security-section claims about argv/env/error handling all match the code — except "sanitized" wording → finding 4 and the incomplete example → finding 5.
7. Data written: enumerated below; the verbatim-payload concern is finding 4 and the README does warn operators to protect stored reports.
