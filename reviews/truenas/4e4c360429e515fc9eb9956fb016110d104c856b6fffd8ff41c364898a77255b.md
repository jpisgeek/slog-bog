## Checked and clean
1. **Secrets/identifying info** — searched all four files for tokens, keys, PEM, cookies, emails, hostnames, domains (only `example.com`, `github.com/jpisgeek`), IPs (none), vault item names (`'myvault', '<your-truenas-api-key-item>'` — placeholders), absolute local paths (none; the only path-like string is the generic relative `.swamp/pulled-extensions/@swamp/ssh/...` at ~line 690, not operator-specific), control chars (`\u001f` written as an escape at 276; no raw NUL/control bytes visible). LICENSE carries the author's name as MIT requires; author is already public as `@jpisgeek`. Clean apart from note 7.
2. **Credential handling** — `apiKey` has `.meta({ sensitive: true })` (44); sent only in the JSON-RPC frame body (512/563); never in URL, tags, instance names, resource fields, or logs; RPC error path drops middlewared `data` (394–405); userinfo in `baseUrl` rejected (82–87); nothing written to disk. Clean.
3. **Transport** — `https://`→`wss://` required by default; no TLS-verify toggle exists; `file:`/`data:` rejected by the `^https?://` regex + `new URL`; WebSocket handshake does not follow downgrade redirects; connect and every call carry a timeout; abort is distinguished from timeout ("aborted" vs "timed out") — see findings 1, 4, 7. No vendor-domain check applies (self-hosted endpoint).
4. **Untrusted input** — all five responses validated with zod before any write or prune; non-array results throw (591–604); `Promise.all` makes a failed sub-fetch abort the whole run so no partial "healthy" state is written; no HTML, shell, SQL, or file-path sinks; instance names slugged + FNV-1a of raw identity joined by `\u001f` (270–291); missing `healthy`/`dismissed` fail safe — see findings 3, 6.
5. **Supply chain** — sole import `npm:zod@4` (sanctioned bare major); `dependencies: []`; no dynamic `import()`, `eval`, `new Function`, or runtime fetch of code. Clean.
6. **Docs vs code** — argument names/types/defaults, method name and arity, six resource kinds and every field list, lifetimes, and the example YAML all match `model` in truenas.ts; `timeoutSec` has no `.describe()` so the README cell is blank (consistent, cosmetic) — see findings 2, 5, 9.
7. **Data written** — enumerated below; README:82–83 discloses hostname, serials, alert text, cert CNs. No write can include the API key — see finding 10.

## Data written by this extension
- `system` (1, fixed name; tag `hostname`) — `hostname`, `version`, `model`, `cores`, `physmemBytes`, `uptimeSeconds`, `loadavg`. **Personal/identifying:** hostname.
- `pool` (per ZFS pool; tags `healthy`, `status`) — name, status, health, capacity, fragmentation. Pool names may be site-specific.
- `disk` (per physical disk; tags `pool`, `type`) — `name`, `serial`, `model`, `sizeBytes`, `type`, `pool`. **Personal/identifying:** disk serial numbers (hardware inventory).
- `alert` (per active alert incl. dismissed; tags `level`, `klass`, `silenced`) — `id`, `klass`, `level`, `formatted`, `dismissed`, `silenced`. **Personal/identifying:** `formatted` free text may contain IPs, usernames, share paths, serials.
- `certificate` (per cert/CSR; tags `expiringSoon`, `expired`, `expiryKnown`) — `name`, `commonName`, `notAfter`, `daysRemaining` (−9999 sentinel when `expiryKnown: false`), `expiryKnown`, `expiringSoon`, `expired`. **Identifying:** certificate names and CNs (domain names).
- `summary` (1, fixed name; tags `poolsUnhealthy`, `certsExpiring`) — hostname, version, counts, `syncedAt`. **Identifying:** hostname.
- Pruning: deletes any stored instance of this model not seen in the current run (`dataRepository.delete`, ~line 695). No secrets in any write.
